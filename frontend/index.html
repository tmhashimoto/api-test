API Lesson

なぜ構造体をそのまま送らず、
JSONに変換するのか

両方を JSON 風に書くと見分けがつきません。 下のデモでは、構造体を Goの書き方、JSONを 送るためのテキスト として並べて見せます。

ポイント（ここだけ覚えればOK）

  1. 構造体は Go のメモリ上の「型付きデータ」。 他の言語やブラウザはそのまま読めません。
  2. JSONは言語を問わず使える「テキストの約束事」。 HTTPでデータをやり取りするときの共通語です。
  3. だから API では 構造体 ↔ JSON の変換が必要になります。
